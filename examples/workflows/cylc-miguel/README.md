# Sandbox for Cylc exploration

`./environment.yaml`: conda environment for installing cylc
`flow*.cylc`: examples of cylc flow definitions to be checked with:

    ```bash
    cylc graph . [start] [stop]
    ```
`runtime-introduction`: introduction to the runtime tutorial
    (https://cylc.github.io/cylc-doc/stable/html/tutorial/runtime/introduction.html#admonition-7)
